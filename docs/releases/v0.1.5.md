# Rail Builder v0.1.5 — Minecraft 1.21.11

A stabilization and inventory-safety release for the existing Minecraft 1.21.11
Meteor addon. This is not a Minecraft version upgrade.

## Changes

* Stabilized development runtime dependencies: load one complete Meteor Baritone
  mod rather than compiling against an API absent from the development client.
* Fixed missing NetherPathfinder runtime/native initialization in Loom development;
  production continues using Baritone's nested library.
* Added optional `debug-logging` settings to both builders, off by default, with
  state, inventory, synchronization, pathing and failure diagnostics in latest.log.
* Fixed hotbar preparation involving occupied slots and bundles using a verified
  vanilla SWAP; preserve displaced contents and cursor-held stacks, and distinguish
  preparation failures from missing materials without automatic item dropping.
* Improved dependency metadata while retaining exact Minecraft 1.21.11 support.
* Added inventory regressions, real Fabric predicate tests, native/runtime checks,
  distribution checks and an isolated production-JAR compatibility probe.
* Restored automatic Java 21 clean-build verification on pushes and pull requests.
  Routine CI does not publish snapshots or releases.

## Dependencies and installation

Use Minecraft **1.21.11**, Java **21 or later**, and Fabric Loader **0.18.2 or
later**. Install Meteor Client for 1.21.11 and Meteor's complete Baritone mod
(`baritone-meteor`), then place `rail-builder-1.21.11-0.1.5.jar` directly in the
profile's `mods` directory. Remove older active Rail Builder JARs first. Keep
exactly one Baritone installation; do not install API-only Baritone or another
NetherPathfinder copy. The full Fabric API is not a direct Rail Builder dependency;
other mods in a profile may require it.

Metadata permits Meteor `>=1.21.11-37 <1.21.12-` and Baritone
`>=1.21.11- <1.21.12-`. These are loading ranges, not a guarantee for every future
accepted API. The same production binary passed graphical startup with Meteor
builds **37 and 86**, each on Loader **0.18.2 and 0.20.1**, using Baritone snapshot
`1.21.11-20260103.131549-1`. Both modules registered and each client shut down
normally. Other builds remain unverified; other Minecraft versions are unsupported.

The maintainer reports successful manual v0.1.5 testing in the Fabric/Modrinth
profile. Automated startup checks do not replace full gameplay testing across
every dependency combination. See the [compatibility matrix](../DependencyCompatibility.md)
and [release verification record](v0.1.5-verification.md).

Open Meteor's GUI and find PoweredRailBuilder and RoofRailBuilder under
**Linear Build**. Enable `debug-logging` only when investigating a problem;
see [log extraction instructions](../InventoryDiagnostics.md).
